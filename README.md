# Khelo India | Website Redesign

A modern, user friendly redesign concept for the Khelo India website, focused on improving the digital experience for athletes, parents, coaches, schools, and sports enthusiasts across India.

## About the Project

This project reimagines the Khelo India digital experience as a modern sports brand rather than a traditional information heavy government portal.

The goal is to make sports opportunities easier to discover through better navigation, engaging visuals, clear information, and intuitive user journeys.

**Official Website:** https://www.kheloindia.gov.in/

## Key Features

* Modern, sports focused visual identity
* Responsive design for desktop, tablet, and mobile
* Simplified navigation and information architecture
* Sports discovery and exploration
* Athlete and parent focused user journeys
* Sports programme information
* Sports centre discovery interface
* Athlete stories and achievements
* News and events section
* Improved accessibility and usability

## Objectives

1. Make sports opportunities easier to find.
2. Simplify complex information and eligibility requirements.
3. Improve the user experience across devices.
4. Create a more engaging and visually appealing sports platform.
5. Make important information accessible to a wider audience.

## Getting Started

### Prerequisites

Install Node.js and npm if the project uses React or Vite.

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/khelo-india-redesign.git
```

Navigate to the project directory:

```bash
cd khelo-india-redesign
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL displayed in your terminal to preview the website.

### Build for Production

```bash
npm run build
```

For a Vite project, the production files are generally generated in the `dist` directory.

## Deployment

This project can be hosted using GitHub Pages.

For React or Vite projects, configure the correct base path in the Vite configuration and set up a GitHub Actions workflow to build and deploy the website.

Once deployment is complete, the website will be accessible at:

`https://YOUR-USERNAME.github.io/khelo-india-redesign/`

Replace `YOUR-USERNAME` with your GitHub username.
